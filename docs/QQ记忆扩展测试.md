# QQ 记忆扩展测试

这套中文题使用虚构数据。借用 LongMemEval 的多会话、时间、更新和应答空题型，LoCoMo 的原话证据，以及 PersonaMem 对变化后的偏好如何实际采用的检查。借用的是题型和标注思路，下面的题可以直接在 RIN 回放。 [LongMemEval](https://github.com/xiaowu0162/LongMemEval) · [LoCoMo](https://github.com/snap-research/locomo) · [PersonaMem](https://github.com/bowen-upenn/PersonaMem)

```powershell
uv run --locked python tools/check_qq_memory.py --sheet docs/QQ记忆扩展测试.md --json
```

在 `rin-memory` 根目录运行。`--case` 可反复传入题号，`--check` 在有误召回、漏召回或异常状态时退出 1。JSON 包含总计 `summary`、分题型 `by_category` 和逐题 `cases`。比较修改前后时使用同一份题表，对照 `selected`、`injected`、`extra`、`missing`。日常小改可用 [快速题](QQ记忆快速测试.md) 做回归。

## 判分和能力边界

- 主指标是 **无用事实率**。某题带出同主题的其它字段、别人的记录、过时状态或同义重复，都计入分子。应空题和正例完整命中单独看。
- N08 是有证据的纠正前提。带出「已取消、还没约」可以阻止系统顺着问题捏造一个新时间。
- A01 的别名在事实正文中。A02 的别名由提取阶段补到检索字段，正文保持原样。快速题 Q06 保留没有别名的旧事实，便于检查历史数据的表现。
- 自动回放固定事实，评分到 DSH 渲染材料为止。续聊题会传入上一轮用户原话。删除用例按事实所属好友执行，单独跑 I04 也会先删除 A 的记录。

## 测真实写入和对话

用开启记忆的测试好友，按下表从左到右发消息。各行使用表中不同的主题。等原话提交及提取处理完毕，再在同一好友的新段提问。记下事实及原话来源、RIN 入选事实、模型输入里的记忆和 QQ 最终回复。换段时另外核对最近原话有没有带入。

| 检查 | 依次发送或操作 | 提问 | 通过条件 |
|---|---|---|---|
| 查询与购买 | 「这把青石 K8 一般卖多少钱？」→「我买了青石 K8，静音红轴，实付 299 元。」→「纠正一下，我那单实付 289 元。」 | 「我的青石 K8 买了多少钱，什么轴？」 | 首句不产生购买事实。更正后用 289 元，静音红轴仍可用。 |
| 当前与历史 | 「镜桥组的周三晨会定在上午 9:30。」→「改到上午 10:30，地点松林会议室。」 | 分别问镜桥组的周三晨会现在几点、原来几点。 | 分别用 10:30、9:30。问时间时只带时间证据。 |
| 偏好采用 | 「我以前经常点重辣。」→「现在点餐希望清淡，一直不放香菜。」 | 「帮我写一句点餐备注，按我的口味来。」 | 采用清淡、去香菜。 |
| 同名跨好友和删除 | A 发「我订了《星灯》演出的 D7 座」，B 发同一演出的 G9 座。确认两边保存后，在管理台按来源删除 A 的测试消息。 | 两边都问「我《星灯》演出坐哪个座位？」 | A 缺少座位证据，B 仍答 G9。A 的来源不从换段材料或召回里重现。 |
| 换段续聊 | 「我办公室现在用青石 K8，静音红轴。」。在最近原话可随新段带入时触发换段。 | 「那把是什么轴来着？」 | 继续讨论青石 K8，答静音红轴。能在模型输入中找到承接依据。 |
