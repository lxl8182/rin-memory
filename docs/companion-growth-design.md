# 记忆与养成设计决策

> 历史摘要 · 2026-10-27，G 系列。当前状态见 [维护台账](roadmap.md)。[查看完整原稿](https://github.com/lxl8182/rin-memory/blob/0ee569e21d788076389211e4fada827c8e4631c7/docs/companion-growth-design.md).

- 角色的知识、共同经历、当前状态和人格卡分别管理。保留原话与事件，使后续变化有可追溯证据。
- 反思以具体经历为单位，围绕主题归并。成熟成长依赖真实互动和相互独立的来源，角色自述、时间经过和沉默不增加支持。
- 明确教导有单独入口，支持在已保存原话基础上形成可撤销表达规则。自动演化只能改允许的段落，冻结身份保留人工控制。
- 普通聊天只用与本轮有关的材料。主动消息根据事项、约定与素材触发，输出和用户实际收到的内容分开记录。
- 研究比较、未采用的扩展和体验目标见原稿。实施细化见 [第一人称决策](first-person-growth-plan.md)。
